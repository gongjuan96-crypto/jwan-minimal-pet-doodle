# jwan-minimal-pet-doodle

Jwan photo-to-minimal-pet-doodle diptych Skill.

## Features

- Preserve the supplied pet photo in the upper half of a vertical 9:16 image.
- Redraw the same pet below as a centered minimal playful doodle.
- Keep pose, fur, expression, toy interaction, and recognizable anatomy connected to the source.

![Case 01](examples/case-01.png)

## Usage

Use `$jwan-minimal-pet-doodle` followed by one pet photo. Add optional color, caption, or signature requirements.
